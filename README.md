# 🐍 Snake Game 3D – Garden Edition
Snake Game 3D is a polished browser-based Snake game with a colorful garden theme, 3D tilt camera, multiple themes, wrap-around mode, progressive levels, fruit types, bonus golden apples, sound effects, high scores, keyboard and touch controls. Built with pure HTML, CSS and JavaScript, it is lightweight and easy to host on GitHub Pages online worldwide.

## 🎮 Game Description

Eat fruit, grow longer, increase your score, and survive as long as possible. Snake 3D adds a polished 3D presentation to the classic Snake formula, with animated fruit, particle effects, multiple visual themes, progressive difficulty, and a special golden-apple bonus.

## ✨ Features

- 🎮 Classic Snake gameplay with smooth movement
- 🐍 3D-style tilted board and optional flat camera
- 🍎 Multiple fruits: apples, oranges, cherries, strawberries, and grapes
- ⭐ Golden apple bonus worth **+50 points**
- 📈 Progressive levels that increase the game speed
- 🧱 Two gameplay modes: **Walls** and **Wrap-around**
- 🎨 Three themes: **Meadow, Dusk, and LCD**
- 🔊 Built-in sound effects with mute control
- 🏆 Persistent best score using browser `localStorage`
- 💥 Particle effects, score popups, animation, and screen shake
- 📱 Keyboard and touch/swipe controls
- ⚡ No frameworks, libraries, build tools, or backend required

## 🕹️ Controls

| Key / Input | Action |
|---|---|
| `↑ ↓ ← →` | Steer |
| `W A S D` | Steer |
| `Space` | Pause / Resume |
| `Enter` | Start / Restart |
| `P` / `Esc` | Pause |
| `V` | Toggle 3D / Flat camera |
| `T` | Change theme |
| `B` | Toggle Walls / Wrap-around |
| `M` | Toggle sound |
| Touch swipe | Steer on mobile |
| Tap | Start / Pause on touch devices |

## 🚀 Run Locally

No installation is required.

1. Download or clone this repository.
2. Keep these files in the same folder:
   - `index.html`
   - `style.css`
   - `game.js`
3. Open `index.html` in a modern browser.

For the best experience, use Chrome, Edge, Firefox, or Safari.
